Ancestral Flagellar Gene Presence Matrix

Columns are the 50 flagellar genes inferred present at the LBCA-equivalent root (ancestral state reconstruction, family-level hybrid tree). Rows are example GTDB genomes on each side of the deepest split in hybrid_family_backbone_gtdb_grafted.tree (the flagella-gene family-level backbone with real GTDB genome subtrees grafted onto each family leaf) — assigned to the Terrabacteria or Gracilicutes side by which of the tree root's two children a genome's family falls under. Presence/absence per gene is read from flagellar_genes_phyletic_distribution.tsv (count > 0 = present). The number at the end of each row is the total ancestral genes present out of 50. 10 example genomes are shown per side, selected by ranking all candidate genomes on that side by ancestral-gene count (ties broken by total flagellar-gene count across the full ~81-gene family, not just the 50 ancestral ones), then taking genomes top-down while capping at 2 genomes per phylum so no single phylum dominates the row. See build_ancestral_example_genomes.py in this directory to regenerate this selection.
